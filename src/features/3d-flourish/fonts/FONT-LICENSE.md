# Jersey 10 (3D subset)

`jersey10.typeface.json` is a subset of `src/assets/Jersey10-Regular.ttf`
(only the characters `B ! G W A L K F J +`), converted to three.js typeface
JSON so it can be extruded as 3D text.

Licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org

To add characters, re-run the conversion on the original TTF with the full
character list (three.js's TTFLoader produces the same format).
